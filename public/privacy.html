Fact Check Privacy Policy

Effective 23 July 2026

What the extension processes

Fact Check processes the page text, URL, or text you choose to check. It also processes the DeepInfra and Tavily API keys you provide.

How data is used

  • Submitted content is sent to the Fact Check backend to run the check.
  • Claims and evidence are sent to DeepInfra for extraction and verification.
  • Search queries are sent to Tavily to find candidate evidence.
  • Your provider keys authorize those requests and charges remain on your provider accounts.

Storage and retention

Provider keys are stored only in Chrome session storage and are sent again for each new check or retry. The backend does not write provider keys to a database, job snapshot, event, export, or application log. Active jobs and results are held in backend memory and normally expire one hour after completion. A backend restart removes them earlier.

The extension keeps a random installation identifier in Chrome local storage for rate limiting. It is not an account and is not used for advertising or cross-site tracking.

Sharing

Data is shared only with the hosting provider needed to operate the backend and with DeepInfra and Tavily as described above. Fact Check does not sell personal data and does not include advertising or analytics.

Your choices

You can clear provider keys from the extension settings at any time. Closing the browser clears Chrome session storage. Exports are created only when you request them.

Security and limitations

Hosted requests use HTTPS. No system can guarantee absolute security, and AI-generated verdicts can be wrong. Verify important claims against the cited sources.

Contact

Questions and deletion requests can be submitted through the support page.
