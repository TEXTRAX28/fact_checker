Fact Check Support

Report a bug, incorrect result, privacy concern, or security issue by contacting the developer by email.

Email support

What to include

Describe which checking mode you used, what you expected to happen, and what actually happened. You may attach an exported result when useful, but remove private information first.

Never include Gemini API keys, Tavily API keys, passwords, confidential text, or other sensitive information in your email.

Lost jobs

Jobs are stored temporarily in backend memory. If the backend restarts or a job expires, start a new fact check.

Privacy

Read the Fact Check Privacy Policy for information about submitted content, provider keys, data flow, storage, and retention.
